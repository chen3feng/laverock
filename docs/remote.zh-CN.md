# 手机遥控

[English](remote.md) | 中文 · [← 返回首页](../README.zh-CN.md)

同一网络下的手机可以使用整套工作室功能——合成、查看历史、管理音色——没有第二套
前端：手机加载的就是桌面窗口里的同一个 Web 应用。本页说明配对与局域网监听的
工作机制。

## 开启

在电脑上打开 **设置 → 手机遥控 → 局域网访问**。服务端会在本机局域网地址上开启
第二个监听（回环监听保持独立），点击 **生成配对二维码** 会得到二维码和六位
配对码。

用手机相机扫描二维码，或打开旁边的地址并输入配对码。配对结果通过 Cookie 记住，
手机保持已配对状态，直到你在 **设置 → 手机遥控 → 已配对设备** 中撤销。

局域网地址在启动时解析。如果机器切换了网络，请关闭再重新打开局域网访问，
以获取新地址。

## 安全模型

- **回环可信，局域网监听不可信。** 除 `/`、`/api/session` 和 `/api/pair/claim`
  外，所有请求都需要设备令牌，可通过 `Authorization: Bearer …` 或
  `laverock_device` Cookie（`<audio>` 元素与流式响应需要）提供。
- 配对码一次性使用，五分钟过期，八次错误尝试后失效。只有回环端能生成配对码。
- 令牌为 32 个随机字节，仅以 SHA-256 哈希形式保存在 `data/remote.json`
  （权限 0600）。撤销手机在它下一次请求时生效。
- 配对状态与局域网开关在重启后保留（`lan_enabled` 持久化在设置文件中）。

## HTTPS

局域网监听使用自签证书提供 **HTTPS**，证书保存在 `data/tls/`，局域网地址变化时
重新生成。安全上下文是手机使用麦克风录制参考音频的前提。

首次访问时浏览器会提示证书不受信任，选择 **高级 → 继续前往**。二维码旁显示证书
的 SHA-256 指纹，谨慎的用户可以先核对再信任页面。

由于证书是自签的，之前用另一个局域网地址配对过的手机，在证书重新生成后可能再次
看到警告——如果浏览器拒绝 Cookie，撤销该设备后重新配对即可。

## 限制

- 只有同一局域网内的设备能访问该监听；它不会暴露到公网，也没有中继、隧道或账号。
- 手机连接期间桌面应用（或服务端）必须处于运行状态；关闭桌面窗口只是隐藏。
