# 语音质量

[English](quality.md) | 中文 · [← 返回首页](../README.zh-CN.md)

速度只说明引擎能不能用，这一页说它好不好听。下面每个数字都在本机实测：
同一段参考音频、同一组测试文本、同一批本地 ONNX 小模型打分，不依赖任何云端服务。

与 [速度实测](models.zh-CN.md#速度) 互补——那张表量的是延迟，这张表量的是像不像人、像不像本人。

## 测什么

| 指标 | 回答什么问题 | 怎么算 | 怎么读 |
| --- | --- | --- | --- |
| **CER** | 字说对了吗 | SenseVoice 把输出转写成文字，与输入文本算字符级编辑距离（英文也按字符，避免 ASR 把 sea shells 合写成 seashells 就算错） | 0 为满分。十个字错一个就是 0.10，**0.05 以内的差异视为噪声** |
| **难例 CER** | 多音字、绕口令、数字日期、缩写、中英混读 | 同上，逐条用例单独算，见下方「测试材料」 | 这里最能暴露基础文本看不出的短板 |
| **Repeat** | 解码器有没有复读 | 转写文本里重复 n-gram 的占比（中文 4-gram、英文 3-gram） | 大于 0.05 说明某句话在打转 |
| **相似度** | 像不像参考音频里那个人 | CAM++ 说话人嵌入与参考音频的余弦相似度 | 同一人不同录音 ≈ 0.7–0.86；不同人 ≈ 0.2–0.4。仅克隆类引擎有意义 |
| **多次一致性** | 同一句话重跑稳不稳 | 同一句合成三次，两两嵌入余弦的均值 | 1.000 表示确定性输出；越低说明每次声音都在漂 |
| **漂移（最低）** | 长段落里声音稳不稳 | 长段落切成 3 秒窗口逐段求嵌入，取与开头最不像的那个窗口的余弦 | 越接近 1 越稳；低于 ~0.7 听感上会明显换人 |
| **DNSMOS OVR / SIG** | 声音干净吗 | 微软 DNSMOS P.835，9 秒窗口滑窗平均 | 1–5 分。3.0 一般，3.5 良好，4.0+ 优秀 |
| **停占比** | 节奏对不对 | 接近静音帧的占比 | 0.15–0.35 自然；过低显得不换气，过高显得拖沓 |
| **音高跨度** | 有没有语气起伏 | F0 的 p90−p10，单位半音 | 中文朗读大致 5–10；低于 3 会显得平 |
| **字/秒** | 发声部分的语速 | 字数 ÷ 有声时长 | 中文日常对话约 5–7 |

## 测试材料

| 分组 | 用例 |
| --- | --- |
| 基础 | 同一短句 ×3（可复现性）、一句常规文本、一段约 140 字的长段落（漂移、停顿）、一句英文 |
| 难例 | `银行行长说，他重新开始了这段很长的旅程。`（多音字：行/长/重）· `四是四，十是十，十四是十四，四十是四十。`（平翘舌绕口令）· `订单金额 3800.5 元，日期是 2026 年 10 月 30 日，完成率 85%。`（小数、日期、百分号）· `这个 model 的 inference 速度很快，但 latency 还需要优化。`（中英混读）· `She sells sea shells by the sea shore.` · `The API returns an error when the JSON payload is too large.`（英文缩写） |

含数字的用例按**口语形式**比对（`3800.5` → `三千八百点五`，`85%` → `百分之八十五`），
因为 ASR 听到的是词不是阿拉伯数字。这类用例中，读法不同但同样正确也算错，
所以报告里会原文列出各引擎实际说了什么。

### 值得注意

- **qwen3tts 三个变体和 voxcpm2 是唯一在全部难例上干净的引擎**：多音字、数字、缩写零错误，
  最多是英文绕口令拆开一个词，或绕口令里错一个字。
- **chatterbox 的声音最不稳。** 克隆相似度 0.82 不算低，但长段落里最不像的 3 秒窗口只有 0.07
  ——一句话之内就换了个人；数字也读得乱（0.364，"三千八百点五" 成了 "三间先险负五"）。
- **kokoro 是英文引擎。** 英文干净，但中文出来是英文腔的音节（绕口令 1.688、中英混读 0.735）。
  说它自己的语言没问题，换成中文不能用。
- **绕口令最能分出中文模型的档次。** 多数引擎在 0.000–0.062（平翘舌准确），
  chatterbox、dots 和 ming3tts-design/-ip 落在 0.25–0.38，都是把「十」「四」读丢或读重。
- **数字是差距最大的一项。** zipvoice 在中文句子里把 `3800.5` 当英文念（2.364），
  longcat 把零吞了（"三八零零点五"、"一零月三零日"）；其余引擎都读对。
- **cosyvoice 克隆最像（0.88）也最稳**，但英文弱：sea shells 那句成了 "she sells seeaws by the seas"。
  longcat 克隆第二（0.86），英文准确率却最差（0.135）。
- **两个节奏异常：** qwen3tts-custom 音高跨度 20 个半音（有表现力还是不稳要看句子），
  longcat 只有 3.9（偏平）；ming3tts-ip 在长段落里漂到 0.59——除 chatterbox 外唯一低于 0.7 的。

## 怎么读这些数

- **打分时关闭了 STT 的 ITN（逆文本规整）。** 开着 ITN 时，"三千八百点五"会被写成
  "3800.5"，用汉字写成的测试文本反而判错——读得对却被扣分。

- **CER 是 ASR 回环，不是人耳判断。** SenseVoice 自己也会错，人名和数字上更明显；
  两个引擎差 0.02 说明不了什么，差 0.10 才是问题。
- **相似度有天花板。** 参考只有一段录音，同一个人换一次录音再比，也只有 0.7–0.86。
  所以 0.75 的克隆已经接近这个指标的辨识极限，再往上要靠耳朵。
- **多次一致性里有确定性的成分。** 固定随机种子的引擎同样输入会给出逐字节相同的音频
  （天然 1.000），对它而言这一列测的是可复现性，不是随机波动。
- **DNSMOS 是在降噪数据上训的，不是 TTS 专用 MOS。** 它反映的是噪声、杂音、发闷，
  不理解韵律自不自然——要和音高、停占比两列一起看。
- 相似度标 "–" 的引擎不支持克隆。预置音色和声音设计用的是它自己的嗓子，
  这时算与参考音频的相似度只是在量"碰巧有多像"。

## 复现

任何装有 `numpy soundfile librosa onnxruntime` 的虚拟环境都可以；打分模型会在首次运行时自动下载。

```bash
# 1. 启动服务（引擎已安装）
LAVEROCK_MODELS_DIR=... ./target/debug/laverock

# 2. 合成并打分
python3 scripts/eval-quality.py \
  --base http://127.0.0.1:8899 \
  --out /tmp/quality \
  --models /tmp/quality-models \
  --ref path/to/reference.wav \
  --ref-text "这段参考音频的转写" \
  --report quality.md
```

`--engines id1,id2` 只测指定引擎；`--phase synth` / `--phase score` 把合成与打分分开；
`--force` 会重新合成已存在的音频。

执行第 1 步之前，把 STT 引擎 `engine.json` 里的 `"stt": { "use_itn": false }` 关掉
（或复制一份 models 目录、只改这一个字段，再把 `LAVEROCK_MODELS_DIR` 指向副本），
因为这项配置在加载时生效。`--report` 生成的报告里还附有每条难例的实际转写，
数字看起来不对时先看那里。

## 值得补充的指标

下面每一条都能回答当前表格回答不了的问题，成本也不高：

| 指标 | 能说明什么 | 成本 |
| --- | --- | --- |
| UTMOS22 / NISQA | TTS 专用 MOS 预测器，比 DNSMOS 更接近人耳判断 | 一个 torch 模型，约 100 MB |
| MCD 与 F0 轮廓距离 | 韵律像不像本人（不只是音色像） | 需要同一人朗读同一组测试文本 |
| 音素级对齐 | 难例里到底哪个音念错，而不只是错几个字 | MFA 或 wav2vec2 对齐器 |
| 情绪遵从度 | 说"兴奋"时到底兴不兴奋：比较 F0/能量的抬升 | 多合成几条 |
| 长篇稳定性 | 五分钟文档里的分块接缝与缓慢漂移 | 每引擎几分钟 |
| 首包延迟 | 流式界面下的真实体感 | 需要流式支持 |
| 盲听 MOS / CMOS | 唯一能真正定论的指标 | 需要真人听众 |

## 这些数字测不出来的东西

- **人的喜好。** MOS、CMOS 终究要靠耳朵，上面全是代理指标。对排名靠前的几个引擎
  做一轮盲听，才是下一步该做的事。
- **韵律像不像本人。** 声音像（本页）比语气像容易得多——语调、重音、节奏需要
  同一人朗读同一段文本的平行录音才能量化。
- **情绪与风格控制。** "兴奋"听起来兴不兴奋，和"像不像本人"是两个正交的维度。
- **长篇行为。** 这里的段落约 20 秒；五分钟的文档会额外暴露句间衔接、分块接缝
  和缓慢漂移，短段落看不出来。
